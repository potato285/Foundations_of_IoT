# Continuous Lab Evaluation-5: Task 1 - LED Fading using Software PWM

## Description
Hardware timer-driven non-blocking Embedded C application for 8051 that generates software Pulse Width Modulation (PWM) to smoothly fade LED brightness without CPU-blocking delay loops.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `led_fading_software_pwm.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/led_fading_software_pwm.hex`
