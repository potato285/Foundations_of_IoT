# Continuous Lab Evaluation-5: Task 3 - Stepper Motor Speed and Direction Control

## Description
Stepper motor sequence driver generating 4-step/8-step commutation signals on Port 1 to control rotational speed and directional stepping without blocking software delays.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `stepper_motor_speed_control.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/stepper_motor_speed_control.hex`
