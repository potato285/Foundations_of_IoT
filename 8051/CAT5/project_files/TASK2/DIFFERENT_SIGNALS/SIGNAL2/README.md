# Continuous Lab Evaluation-5: Task 2 - Signal 2 (Variable Duty Cycle Waveform)

## Description
Generates periodic signals with dynamically adjusted high/low timer reload periods to achieve variable duty cycle modulation.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `variable_duty_cycle_wave.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/variable_duty_cycle_wave.hex`
