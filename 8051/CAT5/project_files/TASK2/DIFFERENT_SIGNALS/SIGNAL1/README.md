# Continuous Lab Evaluation-5: Task 2 - Signal 1 (Square Wave Generation)

## Description
Square-wave generation firmware utilizing hardware timer interrupts to toggle an output pin at a fixed 50% duty cycle.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `square_wave_generation.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/square_wave_generation.hex`
