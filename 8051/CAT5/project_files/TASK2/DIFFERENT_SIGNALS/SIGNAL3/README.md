# Continuous Lab Evaluation-5: Task 2 - Signal 3 (Pulse Train Generation)

## Description
Precise pulse train sequence generator producing defined burst pulse counts using 8051 hardware timer overflows.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `pulse_train_generation.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/pulse_train_generation.hex`
