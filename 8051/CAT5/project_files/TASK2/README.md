# Continuous Lab Evaluation-5: Task 2 - Variable-Frequency Square-Wave Generation

## Description
Generates periodic square-wave and PWM signals of selectable frequencies using 8051 hardware timers (Timer 0/1) with direct register reload operations.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `variable_frequency_square_wave.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/variable_frequency_square_wave.hex`
