# Continuous Lab Evaluation-7: 16x2 LCD Driver and Dynamic Keypad Movement

## Description
HD44780 4-bit LCD driver with string formatting, 2-row addressing, dynamic numerical rendering, and interactive character navigation controlled via 4x4 matrix keypad inputs.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `lcd_driver_and_keypad_movement.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/lcd_driver_and_keypad_movement.hex`
