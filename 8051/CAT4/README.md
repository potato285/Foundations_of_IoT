# Continuous Lab Evaluation-4: Matrix Keypad, 7-Segment Display, and Multi-LED Controller

## Description
Embedded Human-Machine Interface scanning a 4x4 matrix keypad on Port 2 (P2), displaying numeric keypresses on a 7-segment display on Port 0 (P0), and executing multi-mode LED operations on Port 1 (P1).

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `cat4.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/cat4.hex`
