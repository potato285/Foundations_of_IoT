# Continuous Lab Evaluation-6: Task A - UART Fixed-String Periodic Transmission

## Description
Configures 8051 Hardware UART Mode 1 (8-bit UART with Timer 1 baud rate generator at 9600 baud) for periodic ASCII string transmission to a PC serial terminal.

## Hardware Target
- **Microcontroller**: Atmel AT89S52 (8051 Architecture)
- **Clock Frequency**: 11.0592 MHz / 12 MHz Crystal

## Deliverables
- **Embedded C Source**: `uart_string_transmission.c`
- **Startup Code**: `STARTUP.A51`
- **Keil Project**: `*.uvproj` / `*.uvopt`
- **Compiled Firmware**: `Objects/uart_string_transmission.hex`
